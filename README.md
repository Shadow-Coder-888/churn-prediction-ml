# Customer Churn Prediction System

## Project Overview
Machine learning system to predict customer churn and recommend retention actions.

## Problem Statement
Identify customers likely to churn based on historical customer data.

## Tech Stack
Python, Pandas, Scikit-learn, FastAPI

## Repository Structure
- data/: raw and processed datasets
- notebooks/: EDA and experiments
- src/: ML pipeline
- api/: inference service

## Roadmap
Week 1: Data understanding and preprocessing
Week 2: Model development and evaluation
Week 3: API and deployment
